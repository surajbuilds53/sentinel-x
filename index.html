End-to-End System Architecture (6 Stages)

1. 10s Window Aggregator

Extracts 16 continuous state features capturing volume, timing, and protocol flag kinetics.

2. Sequence Windowing

Rolling 120s windows (12 × 16) with strict 70/15/15 chronological split preventing future leakage.

3. 2-Layer LSTM Backbone

128 hidden units with 3 multi-task heads: Risk (BCE), Stage (CE), and State Reconstructor (MSE).

4. Autoregressive Rollout

Iteratively predicts and re-feeds future state vectors to forecast horizons T+1, T+2, and T+3.

5. Dual-Tier SHAP XAI

Decomposes risk into signed feature drivers (red) vs inhibitors (green) and temporal saliency.

6. SOC Action Trigger

Pre-emptively recommends automated firewall ACL isolation rules before payload execution.
